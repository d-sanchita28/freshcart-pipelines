
# From Git to Gold: Data Engineering Pipelines

**Course:** Data Engineering  
**Institute:** IIITDM Jabalpur

## Project Overview

This repository contains the implementation of the Data Engineering assignment, covering version control, CI/CD, ELT pipelines, machine learning pipeline orchestration, and event streaming.

## Project Structure

- `elt/` - FreshCart ELT pipeline using Snowflake.
- `iris_project/` - Mage ML classification pipeline.
- `stream/` - RabbitMQ dispatcher and driver scripts.
- `tests/` - Automated tests for pipeline components.
- `.github/workflows/` - GitHub Actions CI workflow.

## Technologies

- Python
- Git and GitHub
- GitHub Actions
- Snowflake
- Mage
- RabbitMQ
- pytest

## Assignment Components

- Part A: Git and CI/CD
- Part B: FreshCart ELT on Snowflake
- Part C: ML Pipeline with Mage
- Part D: Food Order Streaming with RabbitMQ
- Part E: Report and Viva
